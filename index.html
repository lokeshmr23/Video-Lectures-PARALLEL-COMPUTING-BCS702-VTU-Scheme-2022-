Exam prep

How to actually prepare for the exam

The 4-step loop that works for every module — the planner already budgets 1× watching, 1× notes and 1× practice for you.

The 4-step routine
  1. Watch in order. Follow M1-L1 → M5-L8. Pause and rewind on the derivations that carry marks: speedup and efficiency, Amdahl’s law, MPI collectives and the CUDA trapezoidal rule.
  2. Write short notes. One page per lecture: definition, algorithm or pseudocode, one worked example, and where it is used.
  3. Solve tutorial problems + previous papers. Attempt first, check the solution after — module by module.
  4. Revise with a one-page summary and quiz. Re-derive the key formulas and directives from memory, then self-test.
How to use these videos
  • Pick a module from the index and watch the lectures in session order.
  • Run the programs yourself — MPI, OpenMP and CUDA examples are meant to be typed out, compiled and timed, not just watched.
  • Check the CO (CO1–CO5) mapped to each module to focus your exam preparation.
  • Revisit the module revision session before each IA test and the SEE.

FAQ

Before you start

Is the series free?
Yes. All lectures are free on YouTube — no registration, no payment, no course fee.
Do I need to watch in a particular order?
Follow session order inside a module (M1-L1 → M5-L8). Modules build on each other, so Module 1 first is the safest route, but each module can be revised on its own.
Which syllabus do these lectures follow?
VTU Scheme 2022, BCS702 Parallel Computing — Semester VII, 3 credits, 8 hours per module. Always cross-check with the official VTU syllabus for the latest revision.
Are all the lectures published yet?
Most of them. Any lecture whose video is not live yet shows a Coming soon badge instead of a link — Module 3, Lecture 7 currently has no video. New lectures are added as they are published, so check back or subscribe on YouTube.
Are these enough for the IA tests and the SEE?
They cover the module content in order. Pair them with your own notes, the tutorial programs and previous VTU question papers — the study planner budgets time for all three.
Where do I ask doubts?
In the comments of that lecture on YouTube. Questions there also help other students working on the same module.
